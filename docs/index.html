How the routing actually works

No hard-coded keyword list decides this — a small local model reads each message first and makes the call, same as a human triaging a support queue.

1. A local model reads your message first

An already-running, free local model classifies intent: is this simple enough to answer locally, or does it need deeper reasoning, real file edits, or multi-step work?

2. Simple tasks stay local — free, private, instant

Summaries, quick facts, formatting, short creative writing, casual conversation — handled entirely on your machine, and it even picks the best-suited installed model for the job.

3. Genuinely hard tasks escalate — using what you already pay for

Complex reasoning, architecture design, or real multi-file coding gets routed to Claude or Codex, using your existing login — not a new, separately-billed API key.

4. You always see why

Every decision is logged with plain-language reasoning, token counts, and cost — a live dashboard, not a black box.

Frequently asked questions

Is TJ AI Partner really free?

Yes — the app itself is free and open source. Local models are always free to run. Claude and Codex usage relies on your existing subscription (Max plan / ChatGPT), so you're not paying anything extra beyond what you already pay for those.

Do I need an Anthropic or OpenAI API key to use this?

No. The app can use your existing claude and codex CLI logins with zero extra setup. Adding a pay-as-you-go API key is entirely optional, for people who want per-token billing instead of a subscription.

How is this more secure than using Claude or ChatGPT directly?

Anything a local model can answer never leaves your Mac. When you do add an API key, it's stored in macOS Keychain — the same secure store macOS itself uses — never in a plain file or database. Every project's file access is off by default and scoped to exactly the folder you choose.

What local models does it support?

Any model available through Ollama — Llama, Qwen, DeepSeek, Gemma, and more. Pull, switch, or delete models directly from the app.

Does it work on Windows or Linux?

Not yet — it's built and tested for macOS on Apple Silicon.

Is my data used to train anything?

No. Local requests stay on your machine entirely. Requests sent to Claude or Codex follow whatever data-use terms your existing Anthropic/OpenAI account already has — this app doesn't add any additional data collection of its own.
